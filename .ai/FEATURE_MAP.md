## CP3.1 — chi tiết trang danh mục

Không copy `woocommerce/archive-product.php`. Dùng hook (theme cha đã gỡ `woocommerce_get_sidebar` ở P4.1; cha cũng set `loop_shop_columns=3`, `loop_shop_per_page=12` ở P4.2).

| Hook / filter | Việc |
| :--- | :--- |
| `woocommerce_before_main_content` (bỏ `woocommerce_output_content_wrapper`, thêm mới) | In `.cp-pagehero` (breadcrumb + `woocommerce_page_title`) + mở `.cp-section > .cp-container > .cp-shop`; in `<aside.cp-shop-aside>` gọi `cp_product_cat_box()` (tái dùng `.cp-side-box`/`.cp-side-cats` của CP3.2); mở `.cp-shop-main` |
| `woocommerce_after_main_content` prio 5 (`cp_shop_desc_below`) | `ob_start` gọi lại `woocommerce_taxonomy_archive_description()` + `woocommerce_product_archive_description()` (đã `remove_action` khỏi `woocommerce_archive_description`); nếu có nội dung → in `.cp-shop-desc > .cp-shop-desc__body` + `<button.cp-shop-desc__toggle>` (span `__more`/`__less`) + `<script>` IIFE toggle class `is-open` + `aria-expanded` |
| `woocommerce_after_main_content` prio 10 (`cp_shop_close`) | Đóng `.cp-shop-main` + `.cp-shop` + `.cp-container` + `.cp-section` |
| filter `loop_shop_per_page` prio 20 → 20 · filter `woocommerce_show_page_title` → `__return_false` | 20 sp/trang (4 cột × 5 dòng); bỏ H1 trùng trong header (pagehero đã in) |
| `woocommerce_before_shop_loop` @19 `cp_shop_toolbar_open` / @35 `cp_shop_toolbar_close` / @25 `cp_price_filter_bar` · `woocommerce_no_products_found` @5 `cp_price_filter_bar` | Bọc `.cp-shop-toolbar` quanh result_count(@20) + ordering(@30); chèn `.cp-price-filter` (4 nút `<a>` link `add_query_arg(min_price/max_price)` trên `get_permalink(shop)`/`get_term_link`, giữ `orderby`; nút active href về base = bỏ lọc). WooCommerce tự lọc qua `posts_clauses` khi có `$_GET['min_price']`/`max_price` — không thêm query logic |
| `woocommerce_before_shop_loop_item_title` prio 5 / 20 | Mở `.cp-card-media` (bọc sale flash + thumbnail) → đóng, mở `.cp-card-body` + in tên `product_cat` (`.cp-card-cat`) |
| `woocommerce_after_shop_loop_item` prio 20 | Đóng `.cp-card-body` |
| `woocommerce_loop_add_to_cart_link` | Thay nút giỏ hàng bằng link "Xem chi tiết" class `cp-card-btn` |
| Guard | Chỉ chạy khi `is_shop() \|\| is_product_taxonomy()` (không đụng single product) |

CSS thêm ở `caophat.css`: `.cp-pagehero`, `.cp-shop` (grid 260px/1fr), `.cp-shop-aside` (sticky), `.cp-shop-main ul.products` → lưới **4 cột** (responsive 1200→3, 900→2), `li.product` → card, `.cp-shop-main .woocommerce-products-header{display:none}`, `.cp-shop-desc*` (thu gọn `max-height:4.8em` + fade, `.is-open` mở), reskin `.woocommerce-pagination` (căn giữa, nút 42px bo tròn, `.prev/.next` → ‹ ›, prefix `.woocommerce` để thắng CSS plugin), `.cp-shop-toolbar` (flex, `.cp-price-filter` `margin-left:auto`), `.cp a.cp-price-filter__btn` (chip bo tròn, `.is-active` nền primary), `.woocommerce-ordering select` (42px, mũi tên SVG data-URI), `.cp-shop-main` (thẻ trắng + `var(--cp-shadow)` như `.cp-side-box`). Sidebar dùng lại `.cp-side-box`/`.cp-side-cats` (khối CP3.2).
